# ThodCanvas

Редактор изображений внутри [ThodHUB](https://github.com/ThodProd/ThodHUB), Windows x64. Нужен ThodHUB 0.1.1 или новее.

Откройте изображение: исходник остаётся нетронутым, автоматическая обработка не запускается.
Рабочий холст и PNG сохраняют исходные размеры. Масштаб экрана не влияет на экспорт.

## Инструменты

- **Рука** — перемещение холста. Пробел или средняя кнопка мыши делают то же самое.
- **Перемещение** — перетаскивание активного слоя.
- **Обрезка** — выделите область и нажмите Enter. Края рамки тянутся, внутри рамки она перемещается, щелчок вне рамки начинает новое выделение. Документ обрезается по рамке целиком, все слои сдвигаются вместе с ним.
- **Кисть** — цвет, размер и мягкость. Выделение ограничивает область рисования.
- **Ластик** — закрашивает выбранным цветом фона. Под параметрами есть квадрат цвета, по умолчанию белый.
- **Стереть** — полностью удаляет пиксели до прозрачности.
- **Заливка** — заливает связную область с учётом допуска цвета.
- **Текст** — щелчок по холсту или кнопка «Добавить текст» создаёт новый текстовый слой. Кегль, цвет и полужирное начертание настраиваются справа.
- **Выделение** — прямоугольник или лассо. Выделение ограничивает кисть, заливку, ластик и удаление.
- **Удаление фона** — щёлкните по фону (выделится связная область по цвету) или обведите область лассо, затем нажмите «Удалить фон». Нейросеть IS-Net работает локально и учитывает выделение; без выделения обрабатывает весь слой. «Удалить выделенное» стирает только выделение без нейросети.

Слои: миниатюра, имя и все действия в одной строке — видимость, блокировка, порядок, дубликат, удаление. Непрозрачность активного слоя — под списком. Правая кнопка мыши на холсте открывает обрезку по выделению, удаление и снятие выделения; на строке слоя — дублирование, порядок и удаление.

## Сочетания клавиш

Ctrl+Z — отмена, Ctrl+Shift+Z / Ctrl+Y — повтор, Ctrl+S — проект, Ctrl+J — дубликат слоя,
Ctrl+A / Ctrl+D — выделить всё / снять, Ctrl+0 — вписать, Delete — удалить выделенное, Esc — снять выделение или рамку.
Колесо — масштаб к курсору, пробел + перетаскивание — панорама, «100%» — исходный масштаб.

## Качество и границы

Фотография не пропускается через уменьшенный предпросмотр. Модель получает копию 1024×1024 только для расчёта маски;
маска растягивается к исходному размеру, а текстура и цветные пиксели не уменьшаются. Точность края зависит от модели и ручной коррекции.
Canvas использует 8-битный цвет sRGB; это не RAW/HDR/CMYK-редактор. PNG экспортируется без потерь после обработки.
Поддерживаются PNG, JPEG, WebP, AVIF, BMP и первый кадр GIF; HEIC/RAW сначала конвертируйте в ThodMedia.
До 64 Мп, 16384 px по стороне, 32 слоёв и 160 Мп суммарно по слоям; при превышении программа объясняет лимит, не уменьшает изображение молча.
IS-Net создаёт маску переднего плана: не генерирует изображения, не дорисовывает скрытые объекты и не восстанавливает фон за удалённым предметом.

## Сборка

`.\scripts\build.ps1 -HubRoot D:\ThodPROD -ModelFile <isnet-general-use.onnx>`

В пакете собственный .NET runtime и ONNX Runtime; пользователю не нужны Python, CUDA или SDK. Модель работает на CPU вне UI.
Исходный код RPC и сегментации адаптирован из ThodProd/ThodMedia (MIT).
После изменений увеличьте версию в csproj и hub/manifest.json, соберите новый пакет и опубликуйте
`hub-vX.Y.Z` с ZIP и `thodhub-release.json`. Размер/SHA вычисляет SDK хаба. Старые assets не заменяйте.
