# ThodCanvas

Редактор изображений внутри [ThodHUB](https://github.com/ThodProd/ThodHUB), Windows x64. Нужен ThodHUB 0.1.1 или новее.

Откройте изображение: исходник остаётся нетронутым, автоматическая обработка не запускается.
Рабочий холст и PNG сохраняют исходные размеры. Масштаб экрана не влияет на экспорт.

- Кисть, мягкий ластик и кисть восстановления исходного слоя; цвет и палитра.
- Стрелки, прямоугольники, эллипсы; Shift для квадрата и круга. Текст, размер, полужирное начертание.
- Прямоугольное и овальное выделение, лассо, связное выделение по цвету, автоластик.
- Настоящая локальная IS-Net: выделение объекта и удаление фона только по кнопке.
- При выделенной области фон удаляется только внутри неё; вне выделения пиксели сохраняются.
- Замена фона цветом/изображением, размытие фона, обводка объекта.
- Слои: добавление, копирование, порядок, видимость, блокировка, непрозрачность и перемещение.
- Отмена и повтор всех изменений документа, включая слои и выделения. До 50 состояний, с ограничением памяти истории 256 МБ.
- Сохранение проекта `.thodcanvas` со слоями и исходниками для восстановления; экспорт PNG с прозрачностью.

Сохраняйте проект перед закрытием; хаб предупредит о несохранённых изменениях. PNG содержит объединённый результат.
Ctrl+Z — отмена, Ctrl+Shift+Z / Ctrl+Y — повтор, Ctrl+S — проект, Ctrl+A / Ctrl+D — выделение / снять.
Колесо — масштаб к курсору, пробел + перетаскивание — панорама, «100%» — исходный масштаб.

## Качество и границы

Фотография не пропускается через уменьшенный предпросмотр: в размере 1200 px работал старый редактор ThodMedia.
Здесь только модель получает уменьшенную копию 1024×1024 для расчёта маски. Эта маска растягивается к исходному
размеру; текстура и цветные пиксели изображения не уменьшаются. Точность края зависит от модели и ручной коррекции.
Canvas использует 8-битный цвет sRGB; это не RAW/HDR/CMYK-редактор. PNG экспортируется без потерь после обработки.
Поддерживаются статические форматы браузера: PNG, JPEG, WebP, AVIF, BMP и первый кадр GIF; HEIC/RAW сначала конвертируйте в ThodMedia.
До 64 Мп, 16384 px по стороне, 32 слоёв и 160 Мп суммарно по слоям; при превышении программа объясняет лимит, не уменьшает изображение молча.
IS-Net создаёт маску переднего плана: не генерирует изображения, не дорисовывает скрытые объекты и не восстанавливает фон за удалённым предметом.

## Сборка

`.\scripts\build.ps1 -HubRoot D:\ThodPROD -ModelFile <isnet-general-use.onnx>`

В пакете собственный .NET runtime и ONNX Runtime; пользователю не нужны Python, CUDA или SDK. Модель работает на CPU вне UI.
Исходный код RPC и сегментации адаптирован из ThodProd/ThodMedia (MIT).
После изменений увеличьте версию в csproj и hub/manifest.json, соберите новый пакет и опубликуйте
`hub-vX.Y.Z` с ZIP и `thodhub-release.json`. Размер/SHA вычисляет SDK хаба. Старые assets не заменяйте.

Функциональную проверку первого выпуска выполняет пользователь по его выбору; сборка и установка пакета проверяются перед публикацией.
